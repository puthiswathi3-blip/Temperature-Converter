##### **Temperature Converter 🌡️**



###### **📌 Project Description**

The Temperature Converter is a Python program that converts temperatures between Celsius, Fahrenheit, and Kelvin. It uses separate functions for each conversion and provides accurate results with two decimal places.



###### **🎯 Objective**

The main objective of this project is to practice Python functions, arithmetic operations, conditional statements, and input validation.



###### **🛠️ Technologies Used**

\- Programming Language: Python

\- Concepts: Functions, arithmetic operators, conditional statements, exception handling, and dictionaries



###### **✨ Features**

\- Converts Celsius to Fahrenheit and Kelvin.

\- Converts Fahrenheit to Celsius and Kelvin.

\- Converts Kelvin to Celsius and Fahrenheit.

\- Validates temperature units and numeric inputs.

\- Checks temperatures below absolute zero.

\- Displays results neatly with two decimal places.



###### **📐 Conversion Formulas**

\- Celsius to Fahrenheit: `(C × 9/5) + 32`

\- Celsius to Kelvin: `C + 273.15`

\- Fahrenheit to Celsius: `(F − 32) × 5/9`

\- Fahrenheit to Kelvin: `(F − 32) × 5/9 + 273.15`

\- Kelvin to Celsius: `K − 273.15`

\- Kelvin to Fahrenheit: `(K − 273.15) × 9/5 + 32`



###### **▶️ How to Run the Program**

1\. Install Python on your computer.

2\. Save the program as `temperature\_converter.py`.

3\. Open a terminal or command prompt.

4\. Navigate to the folder containing the file.

5\. Run the following command: python temperature\_converter.py

6\. Enter the temperature, select the source unit (C, F, or K), and select the target unit.
